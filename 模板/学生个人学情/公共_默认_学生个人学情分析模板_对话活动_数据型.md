## 图表与渲染规范（无依赖版）

**核心要求：单文件 HTML，零外部依赖，离线秒开。**

1. **绝对禁止** 引入任何外部 JS 图表库或 CDN 资源（如 ECharts、Chart.js、D3、Highcharts，不得出现 echarts.min.js、cdn.jsdelivr.net、unpkg.com 等）。报告 HTML 中不得出现 `<script src="https://...">` 或 `<link rel="stylesheet" href="https://...">`。
2. **所有图表必须用纯 SVG 内联绘制**（直接在 HTML 里写 `<svg viewBox="0 0 800 400">…</svg>`），包括柱状图、条形图、雷达图、饼图、折线图、散点图、热力图等。
   - 柱/条：`<rect>`
   - 雷达：`<polygon>` + 网格 `<line>` / `<circle>`
   - 饼图：`<path d="M…A…">` 计算弧度
   - 折线：`<polyline>`
   - 数值标签：`<text>`
   每个 SVG 必须带 `viewBox`、`width="100%"` 自适应宽度与清晰配色。

### 雷达图专项规范（必须遵守）

**最关键：几何一致性。所有"顶点"必须严格对齐。**

- **顶点数 N = 数据维度数**（如 5 个维度就画 5 边形，6 个维度就画 6 边形）。**禁止**网格层用 N、数据层用 N±1，或网格层之间边数不一致。
- **顶点方向统一**：所有同心多边形 + 数据多边形 + 数据点 + 轴线 + 维度标签，都使用同一组 N 个角度方向。第 i 个角度（i = 0..N-1）：`θᵢ = 2π·i/N − π/2`（让第一个顶点朝正上方）。
- **坐标公式**：以中心 (cx, cy) 为基准，半径 R 的第 i 个顶点 = `(cx + R·sin(θᵢ), cy − R·cos(θᵢ))`。**所有同心多边形使用同一个公式**，只是 R 不同。

**网格层（同心多边形，必须 = N 边形）**
- 画 4 个同心 `<polygon>`，半径依次 `R × 1.0` / `0.75` / `0.5` / `0.25`，对应 100% / 75% / 50% / 25% 刻度。
- 颜色：`stroke="#94A3B8"`，`stroke-width="1.5"`，`fill="none"`；最外圈 `stroke-width="2"` 加粗。**禁止** `#F0F0F0` / `#E5E7EB` / `#F5F5F5` 等过浅色。

**轴线**
- 从 (cx, cy) 到每个外圈顶点的 `<line>`，颜色 `#94A3B8`，`stroke-width="1"`，可用 `stroke-dasharray="3 3"` 虚线。

**数据多边形**
- 第 i 个顶点半径 = `(valueᵢ / 100) × R`，按相同角度 θᵢ 计算坐标，画 `<polygon>`，`fill="#0052D9"` + `fill-opacity="0.3"`（**不可低于 0.25**），`stroke="#0052D9"` + `stroke-width="2.5"`。

**数据点**
- 每个顶点 `<circle r="4">`，`fill="#0052D9"`，`stroke="white"` + `stroke-width="1.5"`（白圈+蓝心凸起）。

**维度标签**
- 外圈顶点外侧用 `<text>`，字号 14，加粗，颜色 `#1F2937`，按顶点位置用 `text-anchor="middle"` / `"start"` / `"end"` 调整对齐。

**刻度数字**
- 沿顶部那条轴线（θ₀ 方向，即正上方）在各同心多边形交点旁标 25/50/75/100，字号 10，颜色 `#6B7280`。
3. **进度条/仪表盘** 用纯 CSS 实现（嵌套 div + width:% + border-radius），不需要 SVG 也不需要 JS。
4. **配色与字体** 直接写在 HTML 的 `<style>` 里（`body { font-family: -apple-system, "PingFang SC", "Microsoft YaHei", sans-serif; … }`），整体使用 1 套主色 `#0052D9` + 辅色 `#00A870` / `#ED7B2F` / `#E34D59`，错误/低分用 `#E34D59`，良好用 `#00A870`。
5. **数据-图形对应**：每个图表旁边必须紧跟一个 HTML `<table>`，列出原始数据（指标名 + 数值），方便核对，也利于打印。
6. **报告尺寸**：页面 `max-width: 1000px; margin: auto; padding: 24px;`，打印友好（`@media print` 下隐藏按钮、避免分页切断图表）。
7. **文件可移植性**：用户必须能把整份 HTML 保存为 `.html` 后双击直接打开，看到完整图表——不连网也能 100% 显示。

> **一句话总结：不要让图表等下载，让图表就在 HTML 里。**
